# API routes

Generated by `node scripts/gen-route-docs.mjs` from the controllers. Do not edit by hand.
All paths are under `/api/v1`. Every route either is public, accepts any signed-in user (with the real check in the service), or requires the listed permission(s); a route-scan test fails the build if a route declares none of these.
